# FILM!

## Установка

Ссылка на работающее приложение: https://deniol.film.nomorepartiessbs.ru/

1) Скопируйте docker-compose файл для сборки приложения

2) Создайте .env файл с вашими переменными окружения на основе примера

3) Скопируйте дамп базы данных в нужную директорию

4) Запустите приложение командой image: docker compose -f docker-compose.dev.yaml up
